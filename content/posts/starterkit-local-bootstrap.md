# AI Starter Kit의 로컬 실행과 모델 패키징

## 필요한 실행 범위만 준비하기

`bootstrap.sh`는 전체 앱, LLM CLI, RAG CLI 중 필요한 실행 프로필만 준비합니다. PostgreSQL과 pgvector, Ollama는 운영체제마다 설치 명령과 권한이 달라 자동 설치하지 않았습니다. 대신 설치 여부를 확인한 후 사용자가 자신의 환경에 맞게 설치할 수 있도록 안내하는 데까지 자동화했습니다.

일부 시스템 프로그램은 사용자가 직접 설치해야 하지만, 운영체제별 패키지 관리자를 추측하지 않도록 설치 여부를 확인하고 안내하는 데까지는 자동화했습니다.

로컬 비밀 설정은 Argon2id로 키를 파생한 뒤 AES-256-GCM으로 암호화합니다. POSIX 환경에서는 디렉터리에 0700, 파일에 0600 권한을 적용했습니다. `doctor`는 외부 DB나 API, 모델에 연결하지 않고 준비 상태만 확인합니다. API 키와 DB 비밀값, 로컬 경로가 로그에 남지 않는지도 확인했습니다. 설치 전제와 비밀 설정 테스트 18개가 통과했습니다.

## 모델 레이어를 나눈 패키징

EmbeddingGemma 2 체크포인트가 차지하는 OCI 레이어를 나눴습니다. 의존성 설치와 모델 다운로드, 앱 소스 복사를 분리하고 safetensors 파일을 5개로 분할해 다시 패키징했습니다.

| 측정 항목         | 변경 전                | 변경 후                |
| ------------- | ------------------- | ------------------- |
| 최대 압축 OCI 레이어 | 1,045,410,042 bytes | 365,064,895 bytes   |
| 전체 이미지        | 1,485,314,590 bytes | 1,485,186,451 bytes |
| 레이어 수         | 15                  | 21                  |

가장 큰 레이어의 크기는 줄었지만 전체 이미지 크기는 거의 달라지지 않았습니다. 샤딩 전후 텐서 payload의 SHA-256 일치, linux/amd64 Docker 빌드, Backend health 응답 200, 768차원 임베딩을 확인했습니다.
