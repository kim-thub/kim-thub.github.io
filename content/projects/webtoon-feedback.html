결과물
웹툰 댓글 분석과 피드백 저장 서비스

프로젝트 개요

댓글과 별점 반응이 쌓이면 작가가 작품별 의견을 직접 모아 살펴보기 어렵습니다. 이 서비스는 작품을 등록하고 수집된 반응을 분류해 감성과 유사한 의견을 보여준 뒤, 생성된 피드백을 저장합니다. 크롤링 이후의 Flask 앱이 분석부터 저장까지 이어주는 팀 프로젝트입니다.

서비스 기능

  • 작품 관리

    분석할 웹툰을 등록하고 목록에서 제거합니다.

  • 댓글 반응 분석

    댓글을 라벨과 감성, 유사도 기준으로 분류해 작품에 대한 반응을 살펴봅니다.

  • 피드백 저장

    분석 결과를 바탕으로 Gemini 피드백을 만들고 PocketBase에 저장합니다.

화면 자료

실행 중인 화면 캡처입니다. 기획과 팀 산출물은 프로젝트 문서에서 확인할 수 있습니다.

제가 맡은 일

팀 리더로 일정과 기능 범위를 조율했습니다. 화면 구현 폴더인 static/과 templates/, 크롤러인 toon_clawer/, 최종 발표를 제외한 나머지 코드를 구현했습니다. Flask 라우팅과 Usecase, PocketBase 연결, 라벨링과 감성 분석, 유사도 분석, Gemini 피드백 생성과 저장, 관련 데이터와 모델 리소스를 맡았습니다. 팀원이 담당한 화면과 크롤러는 제 기여로 포함하지 않았습니다.

대표 수정 · 화면 집계와 생성형 피드백의 기준을 맞춤

분석 대상이 아닌 라벨 4가 화면 집계와 Gemini 입력에 남으면, 두 결과가 서로 다른 댓글을 요약할 수 있었습니다. 두 경로에서 같은 제외 기준을 적용했고, 이미 처리한 최신 회차는 다시 분석하지 않도록 정리했습니다.

수정 코드와 수동 확인 범위는 분석 파이프라인 기록에서 확인할 수 있습니다. 자동 테스트나 처리 시간 비교를 수행한 근거는 없습니다.

직접 확인한 범위와 한계

수동 실행 확인

웹툰 등록·삭제, 분석 화면 이동, NLP 결과 생성, PocketBase 저장을 직접 실행했습니다.

자동 성능 수치 없음

자동화 테스트와 처리 시간 비교 자료는 남아 있지 않아 성능 향상이나 자동 검증 결과를 주장하지 않습니다.

모델 경로와 실행 환경이 로컬 설정에 의존합니다. 다른 환경에서 같은 결과를 재현하려면 모델, 경로, 테스트 데이터를 준비해야 합니다.
