Job Process
Automation

채용 메일의 공고를 추출·저장하고 Obsidian 문서의 지원 상태를 다시 DB에 반영한 개인 자동화입니다. 교육 참여 후 개발을 중단했으며, 직접 실행해 확인한 범위만 기록합니다.

개인 기획·설계·구현개발 중단Gmail · SQLite · Obsidian
읽을 순서문제구현 흐름검증과 남은 일

메일 원문을 다시 찾고 기록하는 반복

채용 플랫폼마다 메일 HTML 형식이 달랐고, 원문 확인·중복 판단·공고 기록·지원 상태 갱신을 반복해야 했습니다. 파서가 잘못 읽은 경우 입력을 다시 확인할 수 있도록 Gmail 메시지 ID와 raw·HTML을 보관했습니다.

파서를 분리하고 상태를 되돌려 기록

Gmail 원문→플랫폼별 파서→SQLite→Obsidian→지원 상태 갱신

잡코리아·사람인·고용24의 HTML 차이를 각각의 파서로 다루고, URL·필터를 확인한 뒤 문서를 생성했습니다. 문서 체크 상태를 DB의 IN_PROGRESS로 반영하는 흐름을 구현했습니다.

직접 확인했고, 자동화 테스트는 부족했습니다

실제 메일을 사용해 수집·원본 보관·파서 선택·SQLite 저장·문서 생성·상태 갱신을 눈으로 확인했습니다. 익명 HTML fixture, 자동화 테스트, 중복 입력 제약과 지역 필터 정책은 정리하지 못한 상태입니다.

현재 상태: 교육 참여 후 개발을 중단했습니다. 운영 중인 서비스나 충분히 테스트된 도구로 소개하지 않습니다.
