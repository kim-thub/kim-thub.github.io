# About 최종 수정 — 개인 취향과 일상의 기록

## 반영한 내용

- About의 직무 경험 나열을 제거해 CV·프로젝트 상세와 중복하지 않도록 정리했습니다.
- **엔딩 이후의 이야기**: 다양한 장르의 콘텐츠 감상, 별점 기록, 작품이 끝난 뒤의 상상.
- **나중에 다시 펼칠 것들**: 글·사진·아티클의 수집과 분기별 정리, 연말의 일기·다이어리·캘린더 회고.
- **계속 돌아오는 취향**: 모네의 정원, 생쥐가 나오는 오래된 동화책, 재즈.
- **작은 불편을 그냥 두지 않기**: 강의실 공용 티슈를 직접 보충하는 실제 사례.
- 도입 문단에는 새로운 AI 서비스를 사용해 보고 구현 방식에 호기심을 갖는 습관을 반영했습니다.
- 기존 `배움의 시간`은 유지하되, 화면의 `수강 중` 표기는 제거했습니다.
- Home의 세 번째 카드도 `취향과 관찰의 서랍`으로 변경했습니다.

## 공개 범위와 표현 원칙

- 인터뷰에서 직접 확인할 수 있는 사실만 사용했습니다. 동화 제목처럼 확인되지 않은 이름은 만들어 넣지 않았습니다.
- 건강, 마음 상태, 관계 등 공개할 필요가 없는 민감한 답변은 웹사이트에 싣지 않았습니다.
- 프로젝트 기술 설명이나 CV의 근무 이력을 About 본문에 반복하지 않았습니다.

## 코드 유지보수

- `scripts/build_projects.py`의 생성 스타일 블록에 종료 마커를 바로잡았습니다.
- 이전 빌드에서 누적되던 Home / Projects / Blog / About 스타일 중복을 한 번 정리하도록 했습니다.
- ZIP의 GitHub Pages용 Markdown 게시 Action과 실제 이미지 4개는 변경하지 않았습니다.

## 반영 방법

- GitHub Pages에서 새 About을 보이려면 ZIP의 변경된 `index.html` 및 `scripts/build_projects.py`를 저장소에 반영해야 합니다.
- 새 글 게시 시 기존 `.github/workflows/publish-posts.yml`이 `content/posts/*.md`만 감지합니다.
- 테스트 스위트는 요청에 따라 실행하지 않았습니다. 두 생성 스크립트는 오류 없이 실행됐습니다.
