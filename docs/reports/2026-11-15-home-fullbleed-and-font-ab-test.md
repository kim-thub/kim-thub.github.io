# Home 풀블리드 콜라주 및 서체 A/B 비교

## Home
- 왼쪽 사이드바는 유지합니다.
- Home 상단의 kicker 행과 모션 아래의 Projects/Blog/About 링크 카드를 제거했습니다.
- 기존 C → B → A SVG 모션 아트워크를 사이드바 오른쪽 메인 화면 전체 배경으로 확장했습니다.
- PC는 메인 영역의 뷰포트 높이를 사용하고, 모바일은 사이드바의 실제 높이를 측정해 나머지 화면을 아트워크가 채웁니다.
- 기존 SVG의 모션 및 reduced-motion 대응은 보존했습니다.

## A/B 서체 비교
- 본문 및 UI: NEXON Lv.1 Gothic 유지
- A 제목: 여기어때 잘난체 고딕 (Jalnan Gothic)
- B 제목: 빗썸고딕 Basic
- 사이드바의 A/B 버튼으로 전환하며 선택값은 localStorage에 보존합니다.
- 동일한 미리보기 문장, 동일한 크기, 동일한 종이색 배경을 사용합니다.
  - 제목: 분류되지 않은 조각들 (17px, Bold)
  - 본문: 오래 마음에 남은 것들을 모으고, 시간이 지난 뒤 다시 펼쳐 봅니다. (11px, NEXON)

## 폰트 출처 및 라이선스 참고
- 여기어때 잘난체 고딕: 공식 배포처 https://gccompany.co.kr/font ; 공식 페이지는 타이틀용/정보 전달용의 별도 고딕을 소개합니다. 라이선스는 웹 임베딩 시 사용가이드의 고지 조건을 확인해야 합니다.
- 빗썸고딕 Basic: 공식 배포처 https://bithumbcorp.com/ko/promotion/font.php ; SIL Open Font License 1.1, 웹사이트를 포함한 매체 사용 허용. 한글 2,450자 구성으로 일부 문자에는 fallback이 적용될 수 있습니다.
- A/B 웹폰트 로딩 주소는 각각 Noonnu/jsDelivr의 공개 CDN 경로를 사용합니다.

## 범위
- 기존 프로젝트·Blog·About 콘텐츠 및 UI는 변경하지 않았습니다.
- 폰트 후보를 실제 사이트 전체에 확정 적용한 것이 아니라, 비교를 위한 임시 전환 기능입니다.
- 별도 테스트 스위트는 실행하지 않았습니다.
