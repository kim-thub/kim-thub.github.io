# About interview prompts

About의 개인적인 관심과 취향은 사용자의 답변을 받은 뒤 편집합니다.
기존 CV의 프로젝트·기술 항목을 다시 나열하지 않고, 구체적인 장면과 개인적인 선택을 중심으로 질문합니다.

1. 시간을 잊고 몰입하는 것은 무엇인가요? 최근 실제 사례 하나를 말해 주세요.
2. 자주 저장하거나 수집하는 것은 무엇인가요? 링크, 사진, 문장, 물건, 장소 중 무엇이며 왜 남기나요?
3. 좋아하는 작품·공간·도구·브랜드를 세 가지 꼽는다면 무엇인가요? 세 가지에 공통으로 끌리는 지점은 무엇인가요?
4. 일상에서 그냥 지나치지 못하는 불편이나 이상한 점이 있나요? 최근 직접 바꾸거나 해결한 장면으로 설명해 주세요.
5. 프로젝트와 직업을 빼고도 방문자가 기억했으면 하는 당신의 면은 무엇인가요? 남들이 자주 오해하는 모습과 실제 모습의 차이도 좋습니다.

답변은 짧은 메모나 사례 위주로 적어도 됩니다. 답변에서 구체적인 장면, 반복되는 취향, 본인만의 기준을 골라 About에 편집합니다.
