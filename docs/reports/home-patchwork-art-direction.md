# Home Patchwork Art Direction

## Direction
- Gekidan Inu Curry-inspired analog/digital collage principles: layered cut paper, photographed textures, hand-colored surfaces, irregular object movement, miniature-theatre composition. Do not reproduce characters, exact motifs, or copyrighted artwork.
- Scroll position scrubs the existing C → B → A SVG sequence; scrolling upward reverses it. Native page scrolling remains intact.
- The final scene reveals a patchwork workroom containing six clickable project artifacts using the portfolio's own screenshots and original typographic/diagram fragments.
- Secondary paths lead to Blog, About, and email.
