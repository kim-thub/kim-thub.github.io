# Phase 5 — Craft & Quality

## 목표

Phase 1–4의 시각 언어, C → B → A 시그니처 아트워크, 아카이브 콘텐츠와 인터랙션을 유지하면서 모바일·키보드·확대·직접 URL·브라우저 기록·표와 이미지의 사용성을 마감한다.

## 수정 사항

1. **상세 페이지 제목과 포커스**
   - 프로젝트 템플릿의 원래 제목을 상세 페이지 상단의 단일 `h1`로 이동하고 본문 중복 제목을 제거.
   - 다이어리 글의 Markdown `h1`을 노트 헤더로 승격하고 본문 중복 제목을 제거.
   - 키보드로 라우트를 이동하면 프로젝트·다이어리·Home의 실제 페이지 제목으로 포커스 이동.
   - 포커스된 페이지 제목에 점선 포커스 표시와 스크롤 여백 제공.

2. **키보드 포커스 가시성**
   - 잘린 종이 모양 내비게이션 링크에 포커스될 때 `clip-path`를 해제.
   - 명확한 3px 포커스 링을 제공.

3. **표와 좁은 화면**
   - Markdown 표 헤더에 `scope="col"` 추가.
   - 런타임 표 개선 시 기존 헤더에도 `scope="col"` 보장.
   - 3열 이상 표는 모바일에서 헤더-값 쌍의 요약 카드로 제공.
   - 모바일 요약 영역에 접근 가능한 이름을 부여하고 원본 표는 모바일 카드 표시 시 숨김.

4. **목차 스크롤**
   - 활성 프로젝트 목차 항목을 `scrollIntoView()`로 페이지 전체에 전달하지 않고 목차 컨테이너 내부에서만 이동하도록 수정.
   - `build_projects.py`에도 같은 동작을 반영해 재빌드 후 유지.

5. **대비와 모션**
   - 금색·라벤더·샌드·쿨 페이퍼 카드의 작은 메타데이터 색상을 대비가 더 높은 토큰으로 변경.
   - 프로젝트 헤더의 작은 라벨 대비 개선.
   - 페이지 전환 애니메이션에서 회전을 제거해 뷰포트 바깥으로 튀는 위험을 줄임.
   - 모션 감소 설정에서 기존과 같이 전환 애니메이션을 끔.

## 브라우저 검증

Chromium 144에서 실제 DOM·CSS·JavaScript를 실행해 확인했다.

- 320, 360, 390, 430px에서 Home / Projects / Diary / 프로젝트 상세 / 다이어리 상세 / About 총 24개 화면 조합의 가로 넘침 없음.
- 640 CSS px 뷰포트(1280px 화면에서 200% 확대 시의 가용 폭에 해당)에서 프로젝트 상세 가로 넘침 없음.
- 키보드로 Projects 이동 시 `프로젝트 서가` `h1`에 포커스되고 점선 포커스 표시가 계산됨.
- 다이어리 상세 직접 진입 시 제목이 단일 `h1`로 표시되고 본문 중복 `h1` 없음.
- 프로젝트 상세 제목 승격 및 프로젝트 목차 버튼 7개 생성 확인.
- 모바일 표 2개가 접근 가능한 이름을 가진 요약 카드로 생성되고 원본 표는 모바일에서 숨겨짐.
- 브라우저 뒤로 가기: `#project/spot-radar`에서 `#projects`로 정상 복귀.
- `prefers-reduced-motion: reduce`에서 페이지 전환 animation-name이 `none`.
- SPOT RADAR 3개, Webtoon Feedback 2개 이미지가 화면에 진입한 뒤 정상 로드되고 대체 텍스트 보유.
- 브라우저 JavaScript 런타임 오류 0건.

## 남은 한계

- NVDA, VoiceOver 등 실제 스크린리더를 이용한 사용자 검증은 수행하지 않았다. 이번 단계에서는 시맨틱 제목, 표 헤더, 접근 가능한 이름, 키보드 포커스를 코드와 브라우저 DOM으로 확인했다.
- 색상 대비 자동 검사는 작은 메타데이터가 놓이는 주요 카드 표면 조합을 대상으로 했다. 사이트의 모든 상태·모든 조합에 대한 전체 WCAG 감사로 해석하면 안 된다.
- 공개 배포는 하지 않았다.
