# 넥슨 Lv.1 고딕 단일 서체 적용 기록

2026-11-14 · 원본 HTML UI와 콘텐츠는 유지하고 본문·제목·UI·장식 라벨을 넥슨 Lv.1 고딕으로 통일했다.

| 역할 | 적용 서체 | 비고 |
| --- | --- | --- |
| 본문 | 넥슨 Lv.1 고딕 Regular | 프로젝트 카드, 상세 설명, 블로그 문단, About 문단 |
| 제목·UI | 넥슨 Lv.1 고딕 Bold / Regular | 큰 제목, 내비게이션, 카드 이름, 메타데이터, 버튼 |
| 라벨·번호 | 넥슨 Lv.1 고딕 Regular | 프로젝트 표본 번호, Blog 글 번호, 작은 라벨 |

글꼴 종류를 늘리지 않고 크기·굵기·자간으로 계층을 구분한다. 긴 코드 블록과 인라인 코드는 정렬 및 가독성을 위해 시스템 고정폭 서체를 유지한다.

## 글꼴 로딩 및 배포

- 넥슨 Lv.1 고딕 Regular/Bold는 외부 HTTPS 웹폰트 주소에서 로딩된다.
- 네트워크 오류에도 텍스트가 보이도록 기존 `assets/noto-sans-cjk-kr.woff`를 대체 글꼴로 남겨 두었다.
- ZIP은 GitHub Pages의 정적 파일로 배포 가능하지만, 외부 서체 CDN이 차단되거나 응답하지 않으면 대체 글꼴로 표시된다. 완전한 독립 배포에는 사용 허가를 확인한 글꼴 파일을 로컬로 포함하는 작업이 필요하다.

## 추천(미적용)

한 가지 보조 글꼴로 **네이버 마루 부리**를 제안한다. 넥슨 고딕의 단정한 민부리 형태와 대비되는 부리체라 편집·아카이브 콘셉트의 짧은 인용문이나 특별 제목에만 제한적으로 쓰기 좋다. 이번 HTML에는 적용하지 않았다.
